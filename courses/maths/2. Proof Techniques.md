# Proof Techniques

## 2.1 Direct Proof

**Definition 2.1.** A direct proof starts from the initial hypotheses and chains logical deductions until the conclusion is reached.

**Property 2.1.** If the hypotheses are true and each step of the reasoning is logically valid, then the conclusion is true.

*Proof.* A direct proof is a sequence of logical implications. If the initial hypotheses are true and each implication preserves truth, then the final assertion is necessarily true.

**Example 2.1.** If n is even, then n = 2k for some integer k. Then n² = 4k², which is even.



## 2.2 Proof by Cases

**Definition 2.2.** A proof by cases divides a problem into several possible situations and establishes the property in each case.

**Property 2.2.** If a property holds in all possible cases, then it holds in general.

*Proof.* The set of cases considered covers all possible situations. Thus, whatever situation is encountered, the property is satisfied, and it therefore holds unconditionally.

**Example 2.2.** For every integer n, n(n + 1) is even. Either n is even, or n + 1 is even; in both cases, the product is even.



## 2.3 Proof by Contraposition

**Definition 2.3.** A proof by contraposition establishes an implication P ⇒ Q by proving ¬Q ⇒ ¬P.

**Property 2.3.** An implication is logically equivalent to its contrapositive.

*Proof.* The formulas P ⇒ Q and ¬Q ⇒ ¬P have exactly the same truth values under every interpretation. They are therefore logically equivalent.

**Example 2.3.** If n² is even, then n is even. We prove the contrapositive: if n is odd, then n² is odd.

Suppose n is odd. By definition, there exists an integer k such that n = 2k + 1. Then:

$$n^2 = (2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$$

Since 2k² + 2k is an integer, n² = 2m + 1 with m = 2k² + 2k ∈ ℤ. Thus n² is odd.



## 2.4 Proof by Induction

**Definition 2.4.** Proof by induction establishes a property for every natural number using a base case and an inductive step.

**Property 2.4.** If a property holds for an initial integer and is hereditary, then it holds for every natural number.

*Proof.* The base case guarantees that the property holds at the start. The inductive step shows that truth is transmitted from n to n + 1. The property therefore holds for every natural number.

**Example 2.4.** For every n ∈ ℕ:

$$1 + 2 + \cdots + n = \frac{n(n+1)}{2}$$

Base case: For n = 1, 1 = 1·(1+1)/2 = 1. The property holds at rank 1.

Inductive step: Suppose the property holds for some n ∈ ℕ, i.e. 1 + 2 + ⋯ + n = n(n+1)/2. Then for n + 1:

$$1 + 2 + \cdots + n + (n+1) = \frac{n(n+1)}{2} + (n+1) = \frac{n(n+1) + 2(n+1)}{2} = \frac{(n+1)(n+2)}{2}$$

The property holds for n + 1. By the principle of induction, it holds for every n ∈ ℕ.



## 2.5 Proof by Contradiction

**Definition 2.5.** A proof by contradiction assumes the negation of a proposition and shows that this assumption leads to a contradiction.

**Property 2.5.** If the negation of a proposition leads to a contradiction, then the proposition is true.

*Proof.* A contradiction means the initial hypothesis is impossible. Since the negation of the proposition is false, the proposition itself is true.

**Example 2.5.** There are infinitely many prime numbers.

Suppose, for contradiction, that there exists a largest prime number, denoted pₘₐₓ. Then the list of all primes would be finite: p₁ = 2, p₂ = 3, …, pₘₐₓ.

Consider the number N = p₁ p₂ ⋯ pₘₐₓ + 1. By construction, N is greater than all existing primes. Moreover, N is not divisible by any pᵢ, since dividing N by pᵢ leaves a remainder of 1.

Thus N is either prime, or divisible by a prime not in our list, which contradicts the existence of a largest prime.
